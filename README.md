# Sandhimitra

Native Android (Kotlin, Jetpack Compose, Material 3) app for learning Sanskrit Sandhi, with the offline rule-based engine **Sandhātrī (ಸಂಧಾತ್ರೀ)**.
Interface languages: Sanskrit (default), Kannada, English. Theme: Indigo & Copper. No network permission.

* APK: `dist/Sandhimitra-1.0.0.apk` (release, v2-signed with `release/sandhimitra-release.jks`)
* Build: see `BUILD_INSTRUCTIONS.md`. Tests: `TEST_REPORT.md`. Limits and open items: `KNOWN_LIMITATIONS.md`.
* Reports: `docs/` (scholarly coverage, lexical, assets, UI/navigation, fonts, naming, source discrepancies).
* Originals of every supplied file are kept untouched in `original_assets/`.
